Device configuration for Motorola moto g05 / g15 / g15 power
=============================================================

The Motorola moto g05 (codenamed _"lamul"_), moto g15 and moto g15 power
(both codenamed _"lamu"_) are budget smartphones from Motorola.

They were announced in December 2024 and released in January–February 2025.
